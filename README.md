# A Journey Through Art History

A responsive, editorial-style art history timeline, from the Renaissance to contemporary art. Built as a lightweight static site with plain HTML, CSS, and JavaScript—no build step required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. Artwork images load from Wikimedia Commons; an internet connection is needed to display them.

## Features

- Fourteen movements in chronological order, with approximate dates, context, defining techniques, and notable artists
- Representative artwork images with descriptive alt text and source links
- Responsive timeline layout, mobile navigation, smooth scrolling, and gentle reveal/hover effects
- Reduced-motion support and semantic page sections

## Publish

The repository can be published with GitHub Pages by selecting the `main` branch and `/ (root)` as the Pages source in repository settings.
